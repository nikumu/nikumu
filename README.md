## 👋 About me

I’m **André Bianchi**, a **Front-End Web Developer** with over **2 years of experience** building dynamic, responsive and visually engaging web interfaces.

I enjoy creating clean, accessible and user-friendly experiences using **HTML**, **CSS**, **JavaScript**, **React** and **Angular**. I’m especially interested in projects that combine strong visual design, good performance and thoughtful user interaction.

Beyond front-end development, I’m also interested in **compilers**, **programming paradigms**, **machine learning** and the way these areas can expand what we build on the web.
